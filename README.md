# Rukana Art — Public website

Website: https://rukana-art.github.io/rukana-art-site/

This repository contains only the files used by the public website. It is a fresh publication snapshot, not a clone or fork of the artwork archive. Full-resolution originals and historical source files are not included.

Gallery artwork is published as reduced-resolution, watermarked WebP previews. Website content and artwork remain © Rukana Art. All rights reserved. No permission to reproduce, modify, or commercially reuse the artwork is granted by this repository being public.

The site is static HTML/CSS/JavaScript. GitHub Pages should publish from the `main` branch, `/ (root)`. Only reviewed public website files should be committed here; never add original artwork, private source folders, backups, or build-time secrets.
